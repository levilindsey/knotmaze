# K1139 S3a: pulse bands, CPU side (Muse run 15G)

The coordinator's brief, 2026-11-03. One run for Muse, on master, after
run 15F.

## Why

K1139 (Levi, 2026-11-03): "we have to make pulses animate correctly
across junctions".

S2 (run 15A, 16246c90) made one light field over the lit tree. Each
arm's light now starts where the last arm's light ended (P1 at most
0.001 on the stands). The fan still draws its bars, though, so a fork
looks like option B, and Levi chose option A: the light splits along
the paths.

S3a builds the bands that will carry the light through the fan. It is
all CPU work: the bands' geometry, their specs and the crest's CPU
mirror. S3b puts the bands in the fan shader, on the phone, with a
sheet for Levi.

## The run

1. Band specs in `pulse_path.ts`. At each junction the light passes
   through, one band runs from the parent arm into each child arm.
   Behind you, the band runs into the arrival.
2. Pulse bands in `junction_routes.ts`, sharing slots with the gold
   band. Behind you, a 4-arm junction uses 3 bands, plus gold sharing
   one (the plan's Risks).
3. The band crest's CPU mirror in `paint_math.ts`: one crest function
   that both `kPulseV` and the bands call. `kPulseV`'s values must not
   change, because `test/render/paint_gameplay.test.ts` pins them.
4. Tests:
   - T10 in `test/render/pulse_path.test.ts`;
   - the new bands in `test/render/junction_routes.test.ts`.

   K81's existing tests in that file (`legRoutes`, `traveledRoutes`,
   `pickRoutes`, `routeCorner`, `routeCubic`) must stay green unchanged.
5. The hook `__knotPulseBands()`, beside the other `__knot*` hooks in
   `src/app/probe_hooks.ts`. For each band it reports the junction, the
   arms, the slot and the geometry.
6. The stand record. On the five stands of 4.4 (copy the stand links
   verbatim from the harness):
   - dump the bands with the hook;
   - draw the CPU mirror's band kymograph through the fan.

   P1-P5 must hold through the fan. The record goes in
   `.claude/probes/K1139/out/s3a/`.
7. Nothing on screen changes in S3a, because the fan reads no pulse band
   until S3b. Check this with a same-state A/B on the five stands:
   master against your build, with the clocks pinned by
   `__knotPinClocks`. No pixel should differ. If any pixel moves, stop
   and report.
8. Run `npm test`, then commit and push. CI must be green after the
   push.

Done:
- T10 is green, and `npm test` passes.
- No golden pin moves: `test/physics/byte_identity.test.ts`, the K87
  pin, the golden dailies, and `paint_gameplay`'s `kPulseV`. If one
  moves, stop and report it instead of re-freezing it.
- P1-P5 hold through the fan on all five stands.
- The A/B shows 0 px different.

Ports: 5620-5639. These are K1139's own ports; the harness defaults to
5620 through `K1139_HOST`.
