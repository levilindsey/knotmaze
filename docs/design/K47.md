# K47 + K56 brief: saved daily attempts, and the daily as the front door

Levi's decisions, 2026-10-12:
- K47: "Yes, in-progress attempts should be saved."
- K56: "Visiting the app with no query params triggers the daily
  experience. Visiting with query params, or opening the panel and
  editing params, will then cancel the daily treatment."

Context: the daily maze shipped in 3b3e028 (K20): `?daily`, `?daily=N`,
`?daily=N.<delta>`, `DAILY_V1` in `src/ui/daily_link.ts`, and records in
the versioned localStorage document `knotmaze.daily`. CLAUDE.md has its
entry.

## K56: the front door

- **No query string at all, or an empty one: today's daily**, with the
  full daily treatment (HUD title, recorded result, stats, share). The
  address bar stays bare while the daily is on screen.
- `?daily` and `?daily=N` stay the explicit daily links (the share text
  links `?daily=N`). Rewrite `?daily` to the bare URL, since they now mean
  the same thing.
- **Any other query is a design link with no daily treatment:** a seed
  token, legacy keys, or seedless overrides such as `?am=instant`.
- `?daily=N.<delta>`: stop generating it. Since a design edit leaves the
  daily, a daily with a changed look no longer exists. Existing ones (only
  today's tests made any) open as a normal design: the daily's design
  plus the delta, without the daily treatment.
- **Editing params in the panel leaves the daily.** That covers anything
  that changes the maze, its look or the play: structure, look, fog,
  pathViz, moveSpeed (it affects the timer), the seed dice and seed
  entry. The page becomes a normal design link with a toast ("Left Daily
  #N. Your attempt is saved."), and the panel's "Daily #N" button goes
  back to it.
- **Exempt (playback preferences that don't leave the daily):** volume,
  sound mode, camera mode, showStats, and panel open/close and scroll.
  List the final exempt set in your report; Levi will confirm it.

## K47: saved attempts

- **Save** the attempt in progress for day N: moves, path state, the move
  log, elapsed active time (hidden time still doesn't count) and the
  start timestamp. Save after every move and on visibilitychange or
  pagehide.
- **Restore** it whenever day N's daily opens: bare URL, `?daily`,
  `?daily=N`, or the Daily button after leaving. The head dot, gold path
  and timer resume where they were.
- **A reload is no longer a fresh start**, which closes the
  explore-reload-retry loophole.
- **Reset path** inside a daily attempt counts as backtracking to the
  start and the clock keeps running. It never restarts the attempt.
- **A finished attempt** has its official result; later plays are
  replays, as today. Replays need not be saved mid-way unless it is
  trivial.
- **Old days:** an unfinished attempt for an earlier day stays restorable
  through `?daily=N`. Streak rules are unchanged.
- **Storage failures** follow the existing rules: wrapped access, the
  schema version bumped with a migration from v1, quota handling, and
  session-only without storage.
