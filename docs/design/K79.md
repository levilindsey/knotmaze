# K79 brief: background speed, parameters and colors

Levi, 2026-10-12: "The vellum effect can't be animated? In general, with
each background, I'd like a slider that let's us control the animation
speed (zero would be static). Any other relevant parameters would be
welcome too--either general params that apply to all, or individual
params that are conditional to a given background. Background color(s)
should be configurable as well."

## Context

- K21's shader backgrounds: `src/render/background*.ts`, and SHADER
  BACKGROUNDS in `.claude/rules/render.md`.
- Each effect has a drift profile in `background_model.ts` (drift
  multiplier, rate fps, texel scale). vellum is static (drift 0) and
  renders once per change.
- Colors come from the page ink plus three accents of the design's own
  gamut, resent on every recolor.
- The drift pauses after 2.5 s of an otherwise still scene, and stops
  under prefers-reduced-motion.
- Rules that must hold: `none` (and intensity 0) adds nothing to a frame
  (same-state A/B 0 px); fog draws the background.

## Work

1. **An animation speed slider** that applies to the selected background.
   0 is static, and the default reproduces today's speeds exactly (one
   param, conditional on a background being set).
2. **A tasteful motion for vellum.** Probably the mottling and light
   drift; the grain may stay fixed if a moving paper grain reads wrong.
   Whether vellum moves at the default is Levi's call (K52), so default
   it to today's static look.
3. **Other params.** General ones that apply to every effect, and
   per-effect ones that show conditionally (the panel's refreshCond
   map). Pick only params that change the look meaningfully, and show
   each on a contact sheet.
4. **Colors.** Choose between the design's gamut (today's default) and
   custom colors: a base plus one to three accents, whatever the effects
   need. The fog backdrop must keep matching.
5. **Reduced motion.** Keep honoring the OS by default. Propose an
   in-app Motion setting (follow system / full / reduced) as a viewer
   preference, in localStorage like showMazeStats, not a codec param. It
   also governs the pluck's reduced swing and its ghost.
6. **The codec.** New params are APPENDED to the current table (v4 once
   K73 merges; K75 also appends `pulseReach`), with defaults that
   reproduce today's look. Pin them in the codec test.
7. **Cost.** Measure GPU per program under the perf lock, and run the
   phone gate (K10) for any change that renders more often or more
   pixels.

- How it works (files: `src/render/background*.ts`, `src/main.ts`,
  `src/ui/tweakpane_panel.ts`, `url_state.ts`, `param_codec.ts`):
  - `needsShapeProgram` (background_model.ts): an effect switches to its
    shaped program `bg-<id>-x` only when a param that it reads leaves its
    default. Otherwise it keeps its K21 / stage-A program byte for byte;
    `test/render/background_shaders.test.ts` pins those sources by sha256.
  - Scale zooms about the screen center, and the drift time scales by
    1/S. At S < 1 the render texture gets more texels per CSS px:
    `max(base, min(1, base / S))`. Mist, wash, silk and aurora reach 4x
    their default texels at 0.5, contours 1.8x; vellum is already at 1.
  - Vellum's fibers grow at S > 1 and never shrink below their designed
    size. The vignette stays fixed to the screen.
  - Custom mode: the base IS the page (the shader ink, the canvas's CSS
    background, `fabric.setFogColor`). Accent 1 feeds uA2, 2 feeds uA1,
    3 feeds uA3. `BACKGROUND_ACCENTS_USED` lists the accents each effect
    reads, and the panel shows only those rows.
  - Panel: the shape rows have no step. Silk's angle row shows the
    seed's auto angle (the speed row's view pattern). Switching to
    custom with untouched colors copies the design's gamut colors;
    switching back resets untouched ones to their defaults.
  - Probe hooks: `__knotBackground().program`, `__knotBackgroundLayer()`
    and `__knotSetBackgroundParams({...})`, which re-renders and returns
    the program. It does NOT sanitize, so pass in-range values.

### Gotchas

- Headed Chrome off-screen needs `--window-position=2200,50
  --disable-features=CalculateNativeWinOcclusion
  --disable-backgrounding-occluded-windows --disable-renderer-backgrounding`.
- Emulate prefers-reduced-motion as no-preference. This desktop reports
  reduce, which stops every drift.
- Never use `--virtual-time-budget`.
- A bare URL is today's daily. Use links like
  `?k79a.J&am=instant&phy=0&fw=0&snd=none`. Master ignores the new keys,
  so one query serves both builds of an A/B.
- Pin every clock in an A/B. k79_ab pins paint, pulses, the drift clock
  and the fog wobble.
- Pixi skips group uniforms that a program does not declare, so the
  default programs never see uShape.
- An empty value (`bgdt=`) reads 0, not the default.
- k79b_smoke.mjs drives the color mode select by `selectedIndex` plus a
  change event, and finds panel rows by their title.
- Benign console noise: favicon 404s on a fresh profile's first load,
  and "PixiJS Warning: Attribute aUV is not present" (master logs it
  too).
- Ports: leave 5173 alone. B1 used 5341 (branch) and 5342 (master).
- Skipped by design: contrast (it equals intensity), a general drift
  direction, and the vignette.
