### Item 1: the third-arm dim (DATA change, committed 81e9710b)

- Mechanism: run records, no uniform, no shader text, no new program.
  `section_colors.ts` `dimRunTable(table, walk, chains, dims, ink,
  baseHue, dist)` darkens each closed arm's turnstile END toward the page
  ink (TURNSTILE_DIM 0.6) over 1.5 lattice past the junction blend
  (TURNSTILE_DIM_LATTICE). A run that one record covers exactly (strands,
  segments, the rule overrides) keeps that record's colors and ramps;
  any other run (mono's chain-long record, a sweep) gets a fresh
  3-point record. Noise-scheme runs are not dimmed.
- `turnstiles.ts` `closedArmEnds(walk, layout, phase)` names the ends;
  `scene.ts` `withRuleLooks` applies it after `ruleRunTable`, and
  `syncRuleDim()` (SceneRef, called each frame from `frame_loop.ts`
  after the fabric sync) re-uploads only when (controller, layout,
  phase, solved) changes AND the dim set changes. Solved: no dim (the
  bands hide too).
- Tests: `test/core/section_colors.test.ts` "dimRunTable (K138 s4
  turnstile dim)", `test/game/turnstiles.test.ts` "names the closed
  arm's end at the junction".
- Next: page check (`?7&am=instant&snd=none&tst=4`, plus `&xp=fog`).
