# K45 brief: slim CLAUDE.md under the context budget

CLAUDE.md is about 2,100 lines (~36k tokens). Every session and every
agent loads it on every turn. Target: the always-loaded part at about 400
lines and 10k tokens at most (claude-config `rules/context-budget.md`),
WITHOUT LOSING ANY CONTENT. Run this while no other agent is editing
CLAUDE.md, between the G2 merge and the G3/K23 launch.

## Where content goes

- **Stays in CLAUDE.md** (binding for every session): the overview and
  architecture summary; the key design decisions (codec and link rules,
  ParamField, daily pinning); the project structure map; running
  locally; the commit policy; versioning; the short Verification rule;
  and pointers to LEDGER.md, `docs/design/`, `docs/history.md` and the
  rules files.
- **History moves to `docs/history.md`:** the stage-by-stage narrative,
  Stages 0-26, the rounds and the P3 saga, roughly in order. Move it
  verbatim; never import it.
- **Subsystem lore moves to path-scoped `.claude/rules/<area>.md`** with
  `paths:` frontmatter, one area per file:
  - physics: `src/physics/**`, `test/physics/**`, `test/*.regression.test.ts`;
  - render: `src/render/**`;
  - probes and verification: `scripts/**`, `.claude/probes/**`;
  - gameplay, daily and UI where the lore is UI-specific.

  The RENDER LORE / PROBE LORE blocks, the Follow-ups' physics lessons,
  KINK EYES, PER-PIXEL CROSSING GAPS and the rest belong here. Keep each
  file to its area.
- **Track `.claude/rules/`:** change `.gitignore` to ignore `.claude/*`
  except `!.claude/rules/`, so worktrees and probes stay untracked.

## Verification

- **No content lost:** every paragraph of the old file lands in exactly
  one of CLAUDE.md, a rules file or `docs/history.md`. Check it
  mechanically by normalizing whitespace and confirming every old
  sentence exists somewhere new; report the mapping.
- **Under budget:** claude-config's
  `jobs/scripts/_lib/Measure-ContextBudget.ps1` reports knotmaze under
  budget.
- **Rules load:** in a throwaway `claude -p` session inside the repo,
  reading a `src/render/` file loads the render rule, and a `src/physics/`
  file loads the physics rule. Check the transcript, as the claude-config
  agent did.
- `npx vitest run` is still green, and `vitest.config.ts` and the Vite
  watch-ignore still exclude the right paths.

## Conventions

Work in a worktree branch, commit, and don't push; the coordinator
merges. Don't edit LEDGER.md: end the report with Ledger items.
