# K137 stage 6: real-time extras (MinotaurChase's own monsters)

Ledger: K137 (the remainder after stage 5's muddy runs, in
`docs/design/K137_s5.md`'s Handoff order: real-time extras, then the
look pieces). One stage, opus, 2 h cap. Design: the Decided of
`docs/design/K137_s3b.md` ("The monster list onward"): real time gains
`extras: ChaseMonster[]` stepped in `step()` after the minotaur with
the hunter's pursuit; a catch by any resets all (call 1); extras get
no telegraph (call 2). Real-time lures and snares are the NEXT stage
(they ride this one's monster list: `lureDest` / `snared` per monster,
as the turn clock's `TurnPack` already has them).

## This stage

- **Model** (`src/game/minotaur.ts`): a `ChaseMonster` per extra —
  its own Spot, mode, destination, pace state and counter streams
  (own `TurnRng` on the chase seed xor a per-index id, as the turn
  extras draw). Each extra pursues as the hunter model does (the
  params' pace/detect/catch values; no guard/stalker aims, no sword
  flee, no sprint interaction). The primary keeps every behavior and
  every digest it has today when no extras are laid: with zero extras
  nothing below reads or draws the list (the sword/sprint pattern).
- **Count and spots**: a param appended after K799's 222-223 (so
  224), 0-3 extras, panel row + tags. Spots from `sword.ts`'s BFS
  family: 1-3 runs off the optimal route, never adjacent to the
  start, never the primary's lair or each other's run. `carry()` and
  restarts keep tallies; a catch by any monster resets the player to
  the entrance and every monster to its spot (call 1), catches
  counted once per reset.
- **Replay**: extras step inside `step()`, so `replayChase` rebuilds
  them from the same inputs; add a replay digest case with extras.
- **Drawing**: the fabric renderer's minotaur marker gains the
  extras' spots (same glyph, no telegraph ring — call 2); the
  off-screen indicator and `__knotChase()` list them.
- **HUD/stats**: the chase rows name the extras' catches as the
  primary's (one catches tally); no new share tag (s3b Decided).
