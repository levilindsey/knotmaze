## The problem

The production bundle (`dist/assets/*.js`) carries PixiJS, Tweakpane,
simplex-noise and their dependencies with no license text (0 license
comments, measured 2026-10-13). Their MIT, ISC and BSD licenses require the
copyright and permission notice in every copy, so the site must ship them.
Knotmaze itself is all rights reserved (`LICENSE`: Snoring Cat LLC., K117).
The panel shows a credit line (find it in `src/ui/tweakpane_panel.ts`).

## Stage 1 (one agent): research, then the system

1. **Research**, a handful of searches with the sources cited here: how
   web apps and games ship third-party notices (a licenses page or file,
   an about or credits screen, preserved `/*! */` comments, the
   `.LICENSE.txt` files bundlers emit; examples such as Chrome's credits
   page, Android's open source licenses screen, Flutter's license page,
   VS Code's ThirdPartyNotices), and the tooling for this Vite build:
   check whether the repo's Vite version has a built-in license output
   (for example a `build.license` option) before reaching for
   `rollup-plugin-license` or a small plugin of our own. Write the
   findings, the choice and its reasons into "Stage 1 results" below.
2. **Build it**:
   - generated at build time from the modules that actually end up in
     the bundle, not from package.json's dependency list, so it cannot
     drift: each package's name, version, license id and full license
     text with its copyright line, deduplicated;
   - plus hand-written credits from a tracked source file, for what npm
     doesn't know: courtesy credits for the techniques the code comments
     already cite (Quilez's domain warping in
     `src/render/background_shaders.ts`: check the terms of his article's
     snippet; the PCG2D hash, Jarzynski and Olano; interleaved gradient
     noise, Jimenez), and a place for the Hershey acknowledgements (A. V.
     Hershey, NBS; James Hurt, Cognition, Inc.), which must ship with the
     font data once K115 adds it;
   - served next to the app as a page a phone can read, linked from the
     panel's credit line. Use relative URLs: the Vite base is "./", and
     levi.dev proxies the site at https://levi.dev/knotmaze/
     (CLAUDE.md, Commit Policy);
   - a guard (a test or a build check) that fails when a bundled package
     has no license text, or a license outside an allowed list (MIT, ISC,
     BSD-2/3-Clause, Apache-2.0, 0BSD and the like; anything else is
     flagged for Levi).
3. **Delete** the unused Vite template icons `src/assets/vite.svg` and
   `src/assets/typescript.svg`, after checking nothing imports them.
4. **Guards**: tsc, vitest, `npm run build`; the built page opened in a
   desktop Chrome at a phone viewport (411x753), reached through the
   panel's link. Nothing else at runtime changes, so no phone gate (the
   coordinator's call).
5. **Boundary**: write "Stage 1 results" below, commit, stop.
