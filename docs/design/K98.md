## Goal

- **One size slider.** It sets the player's dot diameter relative to the
  thread width:
  - range 0.25-3;
  - the default is the pre-K83 head dot, radius 0.54 tw, so 1.08 tw
    across. K83's discs are 3 tw across today (`markerRadiusFor`), so the
    default look shrinks. Say so in the sheet.
  - The slider sizes the black disc. Each white icon fits inside its disc
    with K83's slight margin (MARKER_MARGIN = MARKER_STROKE).
- **The other in-game icons match the player's.** The start, the finish,
  the minotaur (K80's real-time mode) and every other marker use the same
  size. The edge indicators (K73) are screen-space chrome and are out of
  scope. Levi's settings for them are pending (K198 part 3).
- **Colored dots return at the start and finish.** Each is larger than
  the icon disc, so a colored ring shows at the default. The pre-K83
  discs were 0.95 tw in radius against the head's 0.54. Pick how the
  ring scales with the slider so it shows at every size, and record the
  call.
- **Glyphs.** A simpler minotaur glyph, and a new spider glyph, in
  `src/render/marker_glyphs.ts`, both covered by its fit test. Nothing
  draws a spider yet: K114's spider waits on Levi's call 7. Land the
  glyph and its role ready for it.
- **The param.** Append it to the live codec table (`CODEC_PARAMS`,
  `src/ui/param_codec.ts`), with its default in `PARAM_DEFAULTS`
  (`src/ui/url_state.ts`), and add a panel slider beside the other
  marker or appearance controls. Add it to `DAILY_EXEMPT_KEYS`
  (`src/ui/daily_link.ts`): it changes only the look. Levi reviews that
  list later (K57).
