# K21 brief: shader noise backgrounds

Agent brief, as given on 2026-10-12. Restart an agent from this file if the
work is interrupted. LEDGER K21 holds the live handle.

## The request

Levi: "I'd actually like to render some shader-based noise-based effect.
Research and choose some interesting effects, none too distracting (or
we could tone-down their contrast), and implement a dropdown for
selecting between them."

## What to build

1. Research candidates, then pick 5-6 that are interesting yet calm
   behind a busy celtic weave. Examples: domain-warped fbm, drifting
   curl/flow-noise streaks, soft cellular/Voronoi, paper or linen grain,
   aurora bands, ink-wash clouds, dithered gradients.
2. A full-screen fragment-shader layer drawn first in the main canvas.
   Crossing gaps discard pixels since G1, so the background must show
   correctly through them. If gaps stop reading as gaps, report it rather
   than hacking the gaps.
3. Colors come from the current design: base and background color,
   palette, section gamut.
4. A `background` dropdown (none plus the effects) and a
   contrast/intensity slider. Pick the default (none or the subtlest
   effect) from screenshots and justify it. New params are appended to
   the current codec table: after K19/K20's indices 64-66, never
   reordered.
5. Performance and battery:
   - reduced resolution (a low-res render texture, upscaled) and a
     reduced update rate;
   - measure the GPU cost at 3200x1800;
   - provide a hook for render-on-demand (K24, part of the frame loop K6)
     so a static scene can stop drawing;
   - respect prefers-reduced-motion.
6. Check the interplay with fog of war, the camera (screen-fixed or
   world-anchored: justify the choice), live recolor, the intro reveal,
   and the panel.

## Verification

- Screenshots of every effect at the defaults, the ring link and a
  knot-mode link, at desktop and phone widths. Tune contrast down until
  nothing distracts.
- Same-state A/B: background "none" is pixel-identical to master.
- GPU numbers per effect; tsc, vitest and vite build green.
