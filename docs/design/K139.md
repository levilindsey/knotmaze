# K139: collapse mode

Ledger: K139. One stage, opus, 2 h cap. Sources: K139's note (the last
`## K139` in `docs/ledger_notes.md`) and Levi's line in
`docs/design/levi_notes_2026-10-13.md` (grep "cannot backtrack").

## Levi's words (2026-10-13)

> Another possible gameplay mode: You cannot backtrack, segments
> collapse behind you; try to collapse as much of the level as possible
> while still reaching the finish line. Or, alternatively, without
> reaching the finish line

## Decided

- **The param.** `collapse` (off | finish | free), default off. So the
  dailies, the golden pins, K87 and byte identity do not move.
- **The rule.** Collapse rides K137's snap (`fg=snap`,
  `src/game/fragile.ts`): every run you walk collapses behind you.
  A walk is therefore a trail: no run twice. Junctions stay open.
- **The two modes.**
  - finish: collapse as much as you can and still reach the finish.
  - free: the same without the finish. The game ends when you are
    stranded.
- **Par** is the best possible score, found by a depth-first search
  when the maze is built:
  - finish: the longest trail from the start to the finish;
  - free: the longest trail from the start.

  R.3.4's "longest thread" (`docs/design/K80_gameplay_additions.md`,
  about line 1681) is the same measure, used as a finale.
- **The search is deterministic.** One link builds one maze, with one
  par, on every device (K108).
  - Budget the search in steps (nodes expanded), never in wall-clock
    time.
  - When the budget trips, par is the best trail found. The HUD, the
    banner and the share text must not call it the maximum.
- **The search runs only when collapse is on,** and it never changes
  the maze.

## Your calls

Decide each one and build your recommendation. List each in the Handoff
as a numbered call for Levi, with the alternatives.

1. **The score.** Either the share of the maze's thread length
   collapsed ("as much of the level"), or the number of runs.
2. **How a free game ends.** Only when you are stranded, or also by a
   "done" action.
3. **Stranded short of the finish in finish mode.** For example, a loss
   through K137's `src/app/rule_loss.ts`, with Undo out of it as snap
   allows.
4. **Combining with `fg` and par (`pa`, `par`).** For example, collapse
   overrides fg and brings its own par.
5. **With the chase or the fire,** where there is no Undo.
6. **The look.** Snap's broken run, or something that reads more like a
   collapse.
