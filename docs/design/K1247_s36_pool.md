# K1247 stage 36: the outline worker pool in the app

Ledgers: K1247 (this), K1310 (speed first), K1357 (Levi's drag feel), K1240 (the redesign; the Speed table in
`docs/design/K1240_gate.md`). One Claude Opus agent in its own worktree, on its own branch from master. Cap 2 h.
Read first: the handoff at the end of `docs/design/K1247_s35_route_review.md` (the route table, the pool
prototype, and `### Next stage's brief outline`).

## Why

s35 (merged at e203f246) measured the routes. Nothing reaches the 3 ms gate without a per-frame deadline or GPU
solves. A pool of outline workers is the only route that raises the redraw rate now with low risk and no change
to the look: s35's Chrome prototype (`k1247s35_pool.*`) took def from 14 to 45-52 Hz and fat to 57 Hz at K=5, at
84-89 ms latency, which is below today's app. GPU placement (R1) and frame() cuts (R2) come after this and cut the
work per update inside the pool.

## Goal

`rp=outline` in the app runs its outline on a pool of K workers, and the drawn output for any scene is
bit-identical to one worker's output. The technique is yours; s35's outline is:

- **Dispatch** (`outline_app.ts`, around line 1749): K workers, each with its own OutlineModel and structure. The
  newest scene goes to any idle worker. A reply applies only if its id is newer than the last one applied.
- **K:** from `navigator.hardwareConcurrency`, capped at 4. Measure K = 3, 4 and 5.
- **Structure:** worker 0 builds first and serves, and the others build after its first reply. Building on all K
  at once took 812-863 ms at K=5, against 466-507 at K=1 and the 410 ms bar.
- **Main's budget:** the post (0.8-0.9 ms) and the upload (1.6-2.2 ms per reply) now land on most frames, against
  the 8.5 ms mid-drag bar. Send the scene as transferable typed arrays.
- **Restructures:** each worker restructures on its own `diagramKey` change or throw.
- **Heap:** measure the heap of the K models.

Leave the KF_INC flags and the request's `exact` in place (they are off). Removing them touches `outline.ts`,
where K1314 s13 is working; that is its own item after s13 lands.

## Rules

- PowerShell. Read code through the shell (Select-String, then 40-80 line ranges of Get-Content); never print
  a whole file: outline.ts is over 400 KB. Keep each tool output under about 40 lines (write long results to a
  file and read only the lines you need). Use the Read tool only right before an Edit, and to view images.
  Junction `node_modules` from the main checkout; never `npm ci` or `npm install`. Keep any copy of master's code
  outside `src/` (`paint_ring_lap.test.ts` scans every GLSL file under `src/render`).
- **Your files:** `outline_app.ts`, `outline_worker.ts`, `outline_model.ts`, tests, and tools and outputs under
  `.claude/probes/K1247/` (`k1247s36_*`). Stay out of `outline.ts`, the band files, `rec_glsl.ts` and `paint.ts`
  (K1314 s13). If you truly need a hook in `outline.ts`, keep it minimal and name it in your report.
- **Untracked inputs** (drags, scenes) are in the main checkout's `.claude/probes/`; copy what you need and never
  write there.
- **Commits:** WIP on your branch at each milestone, broken or not. `git add -f` for tools, never for outputs.
  Never push, never edit `LEDGER.md`, never touch the main checkout, never kill a process you did not start.
  Never touch the phone.
- **Perf lock:** `$env:TEMP\claude-perf.lock`, one line (owner, start time, what). Take it only to time, and
  delete it after. While someone else holds it, wait inside one blocking command; a lock older than 30 min is
  stale. Agents share the lock, so expect waits. Mark any number taken under load.
- **Stop** when Done holds or 2 h after your start, whichever comes first (`Get-Date` at the start and at each
  milestone). Before stopping for the cap, run `Get-Date` and check that 2 h have really passed. Leave the last 25
  minutes for the checks. Then commit WIP, append a handoff to this brief with your start and stop times, and
  report. Neither a compaction nor context size is a stop; after a compaction, re-read this brief and `git log`.
