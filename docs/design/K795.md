### Addendum: the beat's run timing (the coordinator's directions, 2026-10-21)

Levi asked that "each segment is traveled in the same amount of time".
He then asked for a toggle between that and the multi-beat runs. This
overrides "Change no defaults" for the beat's run timing only.

- **`beatTiming`** (`btm`, codec 218) has two values:
  - even, the new default: every run takes the same number of beats;
  - length: K114's rule (`beatLength`, `beatCap`).
- **`beatPerRun`** (`btr`, codec 219) is the number of beats every run
  takes under even: an integer in [1, 4], default 1. At 100 bpm one beat
  is 72 ticks, so 0.6 s a run.
- **`src/game/beat_rider.ts`:** `runBeats(length, timing, perRun, unit,
  cap)`.
  - The `BeatRider` constructor still defaults to length, so K114's tests
    keep their expectations.
  - The game passes `beatSettingsOf(params)`, so a design plays even.
- **`src/app/beat_frame.ts`:** `ensure()` rebuilds the rider whenever any
  setting differs, so a caller must pass every field. One missing field
  once rebuilt the rider every frame.
- **`__knotBeat()`** reads `timing` and `perRun`.
- **Links:** `&btm=length` brings back K114's timing.
- **Pins moved by design** (named in `c92ed532`):
  - the codec table pin (two entries appended);
  - `url_codec.test.ts`'s defaults table;
  - OVERRIDE_KEYS (`btm`, `btr`);
  - its off-default values (`beatPerRun` 2);
  - the `beatSettingsOf` expectations.
- **Pins not moved:** the `clk=turn` pins, K87, byte identity, the golden
  dailies and every existing codec entry.
- **The label, a call for Levi.**
  - The coordinator suggested "Beat timing: one per run / by run length".
  - The row reads "same per run" / "by run length", because "Beats per
    run" can make every run 2 to 4 beats.
  - Renaming it is a one-line change to the options object in
    `tweakpane_panel.ts`. The values stay even and length.
- **Not built, as directed:** the beat indicators dropdown (a pulse around
  the head, a pluck centered on it, a crisp ring, or beat dots along the
  runs). It belongs to a later agent.
