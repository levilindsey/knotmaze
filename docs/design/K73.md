# K73 brief: pathViz labels, a longer recentPath, mode badges

Levi, 2026-10-12. Three UI changes, one commit each.

## 1. pathViz labels

"for pathViz, rename 'gold' to 'fullPath', and 'trail' to 'recentPath'."

- Rename the panel LABELS and tooltips only. The internal values ("gold",
  "trail", "string"), the codec option lists, the legacy `pv=` names and
  `trm=1` all stay.
- Comment at the panel row that labels and values differ on purpose.

## 2. recentPath reaches about twice as far

"make recentPath highlight about twice as far".

- `trailLength` (`trl=`) default 5 -> 10; raise the slider max if needed.
- A default change is a new codec version: `CODEC_V4` = v3 with
  trailLength 10, pinned in `test/ui/param_codec.test.ts` as v3 plus its
  one edit.
- v3 links keep their look: a v3 link with the v3 default still decodes
  to 5 (test it). Dailies pin codec v3 (DAILY_V1) and must not move.
- Update the all-default token everywhere it is named (CLAUDE.md Key
  Design Decisions, `.claude/rules/probes.md`): v3's `.c` still parses.

## 3. Mode badges

"when we are not in 'daily' mode, we should show an indicator message in
the corner, next to the settings button (with an explanatory tooltip).
Also, when we are in daily mode, but we are playing a successive attempt
that is no longer representing the official score for the day, we should
indicate that in a similar way."

Recommended to Levi and implemented:
- A small pill left of the hamburger button, top-right, HUD-styled.
  It must not collide with the HUD, the win banner or the open panel,
  must respect safe-area insets, and must be finger-sized under
  `pointer:coarse`.
- Free play: a neutral slate pill with a compass icon ("Free play"). The
  tooltip and aria-label say it isn't today's daily and doesn't count. A
  tap goes to today's daily, as the panel's Daily button does.
- Daily replay: a muted amber pill with a circular-arrow icon ("Replay -
  not scored"). The tooltip says the first finish is the official
  result. On touch, a tap shows the explanation as a toast.
- No badge during an official, unfinished daily attempt. No animation
  under reduced motion. The state decision is a pure, unit-tested
  function.

## 4. Off-screen exit indicator (added the same evening)

"let's add an off-screen target indicator to show the direction of the
finish when the finish is offscreen."

- A chevron on the viewport edge, pointing at the exit marker in its
  color with a dark outline. It is clamped inside the safe-area insets,
  sliding clear of the HUD, the badges, the hamburger, the banner and the
  panel.
- It shows only in fabric mode while the exit is off-screen. It hides
  once solved and during the intro until the exit has revealed. It also
  shows under fog of war, as direction only: a decision for Levi.
- Under reduced motion it is static; otherwise a gentle breathe at most.
  A tap pans the camera to the exit, if that is simple.
- A UI preference (localStorage plus a panel checkbox, default on), not a
  codec param.
