# K132: drop link and daily back-compat (one stage)

Levi, 2026-10-13: "we can ignore keeping support for previous url
params, or preserving mazes from previous control combinations.
Breaking changes are 100% fine. We are not launched." CLAUDE.md's first
Key Design Decision ("Pre-launch: no back-compat") already overrides the
older rules; this stage removes the machinery that kept old links and
old dailies alive, and rewrites the lore that describes it.

## Goal

- **One live codec table.** A new param or enum option appends to it. A
  reorder or a removal bumps the version. A default changes in place,
  with no new version: a link lists only what differs from today's
  defaults, so an old link may come to mean something new, and that is
  accepted.
- **An older or unknown version** falls back to the link's seed and
  today's defaults, with one console warning (the path that unreadable
  blobs already take). A bare `?<seed>` means that seed at today's
  defaults.
- **Remove** the frozen v1-v3 codec tables, `LEGACY_BASE`
  (`src/ui/url_state.ts`), the `?daily=<n>.<delta>` reader (and the delta
  blob code if nothing else uses it), the legacy key renames (`mc`, `trm`)
  and DAILY_V1's frozen v3 base (`src/ui/daily_link.ts`). A daily becomes
  today's defaults, the day's seed and the exempt preferences.
- **Keep:**
  - the `&key=value` overrides after a token, and the `s=` / `seed=` keys
    that probes use (`am`, `mf`, `psz`, `ms`, `fw`, `clk`, ...), read
    against today's defaults;
  - one link building one maze on every device within a build (K108,
    `src/util/det_math.ts`, `test/core/deterministic_math.test.ts`);
  - the pins as change detectors. Re-freeze the golden dailies and the
    K87 plan pin where they move, and name what moved in the commit.
  - a guard that the live table only grows: pin its key order literally,
    so a reorder or a removal fails the test until the version is bumped
    and the pin updated. Keep the test that fails until a new
    `PARAM_DEFAULTS` key is appended.

## What exists (read first)

- `src/ui/param_codec.ts`: the bitstream, the frozen tables and the
  version dispatch. `test/ui/param_codec.test.ts` pins CODEC_V1 literally
  and each later table as its predecessor plus its edits. Drop those
  pins.
- `src/ui/url_state.ts`: link parse and write, legacy forms, defaults.
  `test/ui/url_codec.test.ts`.
- `src/ui/daily_link.ts`: DAILY_V1, seeds, routing (the bare URL is
  today's daily; `?daily`, `?daily=<n>`), the exempt preferences.
  `test/ui/daily_link.test.ts` (golden dailies, the front door, the
  exempt set).
- `src/game/daily_attempt.ts` (K47): a saved attempt whose maze changed
  must be refused cleanly; every daily's maze changes in this stage.
- K146 (merged 2026-10-14) made past dailies playable as practice, and
  the store is at v3 (`src/game/daily_store.ts`). Results are records and
  stay; only attempts are refused.
- Lore that describes the old machinery, to rewrite (shorter, not
  longer): CLAUDE.md (the "URL-as-complete-state" and "Daily maze"
  bullets, and "K132 removes the machinery" in the first bullet);
  `.claude/rules/gameplay.md` (link codec details, the DAILY MAZE binding
  rules); `.claude/rules/generation.md` (what generation changes do to
  the dailies); `.claude/rules/probes.md` (the gotchas about `?<seed>`
  links being v1 and the `.c` / `.U` tokens). A history line goes in
  `docs/history.md`.
