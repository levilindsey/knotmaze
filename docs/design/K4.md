# K4 brief: G2, color work into the shaders

Agent brief, as given on 2026-10-12. The design itself is
`docs/design/G2_shader_paint.md`; this file holds the brief around it. Restart
an agent from both if the work is interrupted. LEDGER K4 holds the live
handle.

## Scope

All per-sample and per-tick color work moves into the shaders, staged as
in the design doc. G2.0 through G2.3 and G2.5 are required. G2.4 (GPU
particles, LEDGER K23) is wanted after G2.3 if the earlier stages verify
cleanly; otherwise it becomes a follow-up.

The design doc predates G1: per-pixel crossing gaps landed in
99443cb..19209c4 (casing masks in the ribbon fragment shader,
`src/render/gap_mask.ts`; over-fills, fade strip and erase grid deleted).
Reconcile the doc with the code first, and record each deviation in it.

Defaults Levi accepted:
- the trail fade becomes the intended linear fade over the oldest 30%;
- burn also applies to single-color threads;
- noise colors stick to the material;
- the ink spread is computed from reveal-start positions;
- ink + burn and knot-mode FX stay off.

## Verification, per stage

- Exactness: keep CPU mirrors for probes and certify the GPU output
  against them with a census, modeled on the GPU JUNCTION FIELD round's
  injected-triangle readback. Run same-state A/B pixel diffs with physics
  frozen, animation clocks pinned and the pointer parked, and attribute
  every changed pixel.
- Coverage:
  - every appearSequence x appearFx combination;
  - the gameplay paint (gold path, pulses, hover, trail fade, string mode,
    fog);
  - every colorScheme at junctionBlend 0 and 0.88;
  - live recolor.
- Performance: main-thread paint and tick cost before and after, and
  draw-phase GPU time at 3200x1800 (start the query at the frame's first
  draw call). Phone numbers when the phone is connected
  (`scripts/phone.ps1`).
- tsc, vitest and vite build green.

## Conventions

- Work in a worktree branch.
- Commit each stage, and WIP at milestones. Never push; the coordinator
  merges.
- Keep probes in `.claude/probes/K4/`.
- Add a G2 entry to CLAUDE.md, within the context budget.
- New params are appended to the current codec table, never reordered.
- Don't edit LEDGER.md: end the report with a Ledger items list.
