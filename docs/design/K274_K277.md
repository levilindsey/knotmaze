**The work:**
1. Write one plain line for each stat the banner can show. The lines go
   under the stars' explanation, in the same popover.
   - Read each formula in the code and describe what it computes. Don't
     trust this brief's paraphrase.
   - One subtlety needs saying plainly. Efficiency is the optimal route
     divided by the route you ended on, with backtracks erased. So a
     wander you walked back can still read 100%, while the stars count
     every step.
   - Check that claim against the code. If the code says otherwise,
     describe the code and flag the difference in the handoff.
2. Keep each line beside its stat's definition, in one table keyed by
   the row's id. Add a test that fails when a row has no line. A later

   can't ship without its line.
3. **The daily stats view:**
   - If it shows the same metrics, or aggregates of them, give it the

     its layout.
   - If it shows none of them, leave it alone.
4. **Phone fit (360 px wide):** the popover scrolls rather than
   overflowing, and the tap targets stay as they are today.

### Wording (binding)

- **Credit as use:** "uses", "follows", "after". Nothing may read as an
  endorsement by, or an affiliation with, the people or owners it names.
- **Game titles can be trademarks.** This covers Robert Abbott's
  *Theseus and the Minotaur* and Wordle.
  - Name them only to describe where an idea came from, never as
    branding, and use no logos.
  - Knotmaze copies none of their levels or designs.
- **No legal claims on the page.** Don't label anything "public domain"
  unless its source says so.
