## This stage, in order

What the cap leaves goes in the Handoff as the remainder.

1. **The minotaur's scent (4.34).** A fading red tint on the runs a
   monster walked, in the gameplay paint (the memory trail's machinery is
   the model). It works on both clocks, and each monster leaves its own.
   Add the param and a panel row.
2. **The fray (4.3's look).** A cracked fragile run draws thinner and
   desaturated before it snaps; the gone look stays. This is a render
   prototype. Under the ledger's binding rules, it skips the CPU mirror
   and the parity tests until Levi picks a look. With the param off,
   master's paint text and every paint test stay as they are.
3. **Darkness and a lantern (4.17).** Fog of war that closes again:
   explored areas fade back to dark behind you, and a lantern lights a
   radius around the head. It is built on the fog machinery (`xp=fog`).
   Add the params and panel rows.
4. **Sonar pluck (4.26).** In fog or darkness, a pluck makes nearby runs
   of the same pitch ring and briefly opens a hole in the fog. It goes
   through the hidden runs' pluck hook. Add an optional ping limit, with
   a HUD row and a share tag when it is limited.
5. **Tunnels (4.13), if the cap allows.** A pair of far-apart junctions
   linked as one move. The link changes the walk graph, so the kit
   (`rule_search.ts`), par and the chase graph must all see it. If it
   does not fit, plan it in the Handoff instead.

Put each mechanism's logic in a pure module with tests: the scent's fade,
the darkness's refill timing, and sonar's choice of runs. With every new
param off, every pin and digest stays identical, the paint census holds
and the golden stays byte-identical. Register every new GL program in
`shader_warmup.ts` (K307).

Then:
- **The page.** Use real taps on desktop and at 411x753 (dsf 2), on seed
  links such as `?7&am=instant&mt=hunter&snd=none` plus the new params.
  Take stills of:
  - the scent behind the minotaur, on each clock;
  - a run fraying, then snapping (`fg=crack`);
  - darkness closing behind the head, and the lantern;
  - a sonar ping in fog;
  - tunnels, if built.

  Make one contact sheet with `.claude/probes/K525/mksheet.mjs`. Stills
  go in `.claude/probes/K137/s4/`.
- **Lore** for what you built.

**Calls.** Build each entry's rec. Where an entry gives none, take the
simplest choice that reads well. List each call in the Handoff with its
alternatives. The known ones:
1. The scent: which monsters leave it (rec: all), and how long it fades
   (in moves on the turn clock, seconds on the real-time clock).
2. The fray: thinner and desaturated, as 4.3 says. How thin and how pale
   goes to Levi as a look call, with a still.
3. Darkness: how soon explored areas close (rec: after a set number of
   moves, or seconds on the real-time clock), and the lantern's radius.
4. Sonar: unlimited pings by default, with an optional limit. Set the
   hole's size and how long it lasts.

**Out of scope:**
