## Question
Lures (a thread you pluck to draw the minotaur to it) and snares (a trap that holds a monster) were built with 20 rule choices. Does any of them need to change?

## Context
All 20 were built as the design doc recommended; the page check passed on a desktop window and a phone-sized window. The weightiest, each with the doc's alternative:
- Both tools take no turn. Alternative: a lure costs a move.
- A lure carries 6 runs, counted along the maze, and a cut or broken run blocks it. Alternatives: straight-line distance, unlimited, or by the thread's pitch.
- A lured minotaur forgets its hunt. Alternatives: a hunting minotaur ignores lures; lures draw a roaming one only.
- A snare goes only on a run at your junction (the one behind you included) and holds 3 turns. Alternatives: any run in sight; 2 turns, or until you are out of sight.
- A held monster can still catch you. Alternative: harmless while held.
- Stocks refill only on a level restart. Alternatives: refill per catch, or one back every N moves.
The other alternatives (the lure's target point, sleepers hearing it, an unheard lure refunded, keys N and L, the snare's look) are in the doc's list.

## After you answer
Silence leaves all 20 as built. To change one, name it and the alternative. The lure's range and the snare's hold are panel rows (`&lrg=`, `&snh=`), so those two can be tried first with no change.
