## Question
When you backtrack off a fully traveled junction, its gold web now fades out over 0.25 s. When you press Reset path, every web vanishes in one frame, as it did before the fade existed. Do you want the reset to fade them too?

## Context
- On 2026-10-14 you answered "fade out" for a web that stops being full. The brief counted a backtrack and a reset alike; only the backtrack could be built, because its web stays on the route. Webs that backtrack together fade on one 0.25 s clock.
- A web that also leaves the route (a reset, switching the string mode, the trail aging out, a path backing off the junction entirely) loses its arms' gold in the same frame. The shader only blends a web whose junction is still on a route, so no gold is left to fade.
- A fading web that loses its last route mid-fade pops from its current level to untraveled.
- A fade there needs the shader to blend a second base for a junction that is no longer on a route, or the arms' gold kept alive through the fade. Both are shader work for a 0.25 s effect on a rare action.

## How to check
1. Open the link, travel every arm of a junction so its web turns gold, then backtrack: the web fades out.
2. Fill another web and press Reset path in the Game folder: the webs vanish at once.
