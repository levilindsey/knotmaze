## Question
In the beat game the dot rides on its own and you only steer it. The extra maze rules (ice, the color rule, turnstiles, hidden runs, one-way runs, locks and keys) still switch on there, though they were never designed or played against it. Drop them under the beat, or keep them?

## Context
- The beat design dropped only the cut, the walker and Undo (its decision 7). The rules pass through unchanged.
- In the code, when the dot's next move is refused the rider tries the next arm in order (straight on, keep right, back) and rests only when every arm is refused. The ledger's worry that a refused move stalls it is therefore partly covered.
- No test and no page run has combined a rule with the beat, so what it feels like is unknown. Hidden runs reveal by a pluck, and the beat plucks every run's note; I found no record of whether those plucks reveal anything.
- These rules are already off in every game mode except the classic game (pinned for the real-time chase), so the beat in the classic game is the one place they meet it.

## Options
- **Drop the rules under the beat (rec)**: a small change where the cut is already dropped; the beat is then plain mazes only.
- **Keep them, as built**: the rider skips refused arms; untested.
- **Design the pairing**: play each rule against the rider and fix what breaks (a larger task).

## How to check
1. Open each link, tap an arm to start the dot and let it ride.
2. Watch whether it ever stops, loops or feels unfair at a closed turnstile, ice or a hidden run.

## After you answer
If drop: a small gate plus the tests that pin it. If keep: the first page check of each rule under the beat.
