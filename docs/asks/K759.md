## Question
Turnstiles and hidden runs were built with five rule choices that the design doc recommended. Does any of them need to change, or do they all stand?

## Context
A turnstile is a junction that keeps one arm closed, and the closed arm changes as you move. A hidden run is a run you cannot see or take until you pluck a thread that sounds the same note. Built, page-checked on a desktop window and a phone-sized window (seed 7, no errors). Each call with the alternative the doc named:
1. The turnstile turns once per move you make, in every mode, real time too. Alternatives: a clock in real time; turn on fresh moves only, not on backtracks.
2. Each turnstile starts at its own seeded position. Alternatives: all start in step; the position comes from the junction's place.
3. Only a pluck of the same note within 3 runs reveals a hidden run. A tap near it, and music mode's automatic plucks, do nothing. Alternatives: any pluck within N runs whatever the note; a reveal that costs a stroke; automatic plucks reveal.
4. Undo past a reveal hides the run again. Alternative: a revealed run stays revealed.
5. Par, strict mode, the stars and the efficiency rate the maze without hidden runs (the HUD also shows the fewest moves with them). Alternatives: rate with them (punishes a player who never finds them); rate with the revealed ones only (a moving target).

## After you answer
Silence leaves all five as built. To change one, name its number and the alternative; each is a rule edit plus a re-check.
