# K617 · Should High contrast make the start, exit and player markers bigger again, and by how much?

kind: decide
asked: 2026-10-20
blocks: nothing (a one-line change)
rec: raise High contrast's marker floor to about 2.75

## Question
High contrast is meant to enlarge the markers, but the default marker size grew to 2 and High contrast only asks for at least 1.5, so turning it on no longer changes them. Should it ask for about 2.75 instead?

## Context
- High contrast (Accessibility folder in the panel) wears a list of looks over your settings: a black page, a yellow route, wider crossing gaps and larger markers. For markers it takes "at least 1.5", and it keeps a larger size you chose yourself.
- When it was built, the default marker size was 1.08, so 1.5 was about 1.4 times larger. K225 then raised the default to 2 (the slider runs 0.25 to 3), so 1.5 is now below it and does nothing for anyone on the default.
- It waits on you because the right size is a design call: 2.75 keeps the old 1.4x look; the agent that found it floated 2.5.

## Options
- **About 2.75 (rec)**: High contrast makes default markers 1.4x larger again. Close to the slider's top (3).
- **2.5 or another size**: the same idea, a smaller step.
- **Leave 1.5**: High contrast no longer enlarges markers on the default; it only lifts a small size you picked.

## How to check
1. Open https://levi.dev/knotmaze/?7&am=instant and note the markers at the default size (2).
2. Open https://levi.dev/knotmaze/?7&am=instant&mks=2.75 and compare: this is what High contrast would show at 2.75.
3. In the panel, open Accessibility and tick High contrast on the first link: today it leaves the markers as they were.

## After you answer
A size: an agent changes the constant in `src/ui/accessibility.ts`, the panel tooltip, the lore note and `docs/design/K111.md`, and restores the test clause that was dropped; the item closes. Leave 1.5: the item closes and the docs say the floor is moot at the default.
