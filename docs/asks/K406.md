## Question

- At 1.5 the blur's inner edge turns +31 to +56 degrees across the tip; at 3 it turns +19 to +42 degrees with a flat arch, for 0.02-0.03 world units less inner swing. 6 looks like 3.
- The numbers were measured on an old test loop that today's `?7` no longer has; the pictures show it.
- It is a code value (`PluckOverlay.capRound`), not a panel setting or a link key, so only the pictures show the 3.

## Options

- **Switch to 3**: the tip's M softens everywhere; K405 then matters less.
