## Question
In the classic game with the extra rules on (one-way runs, ice, turnstiles, keys), a move you regret leaves you only Restart. Should there be an Undo button for it, or is Restart enough?

## Context
Undo works in the game, but no button offers it while these rules are on. The scissors' Undo needs the scissors, which turn the rules off. The Stranded banner, the only message that offers Undo, appears only for fragile runs or collapse, which turn the rules off too.
Traps are common: the rule kit's census says one-way runs plus ice trap the player on 42 of 50 seeds without keys, and on 44 of 50 with 2 keys (K780). The trap itself was inferred from the rules, not seen.

## Options
- **Undo button beside the rules (rec)**: it shows while the rules are on and replays your moves minus the last, as the Stranded banner's Undo does (a slide over ice counts as one move). A trapped player can step back out.
- **A Stranded-style check that offers Undo**: the game notices you are stuck and offers it then. It needs a new check: today nothing checks that every position still reaches the exit under ice plus one-way (the census checks only the start).
- **Restart only**: leave it as is. The cost is a lost run each time.

## How to check
1. Open either link and walk a few runs.
2. Look for an Undo button: none shows while the rules are on, only Restart.

## After you answer
Button: it is wired to the existing Undo. Check: the check is designed first. Restart only: the item closes.
