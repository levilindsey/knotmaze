# K731 · Should a sound mode set in a daily's link survive a reload?

kind: decide
asked: 2026-10-21
blocks: nothing
rec: document it (the smallest fix; a panel choice is already remembered)
link: https://levi.dev/knotmaze/?daily&snd=none | today's daily with sound off set in the link: after it loads the address bar goes bare, so a reload forgets it

## Question
A daily opened with `&snd=none` in its link plays with sound off, but the page then rewrites its address to the bare one (or `?daily=<n>`), so a reload plays music. A Sound mode you set in the panel is remembered for dailies. Should the link's setting stick too, and how?

## Context
- Found by the sound-off fix (K720, 2026-10-21; its Handoff, Residual 2, which cites K717).
- From the code: on a daily, every address write sets `?daily=<n>` or the bare address (`writeParams` in `main.ts`, `dailyQuery`), dropping any other key. A daily keeps its player's playback preferences (sound mode, volume, camera and more, `DAILY_EXEMPT_KEYS`) in the browser's storage, but stores only what you change after it opens, so a value that came from the link is used once and then lost.
- Ordinary designs are not affected: their link token carries `snd`.
- The Motion setting, for comparison, is saved per viewer (`knotmaze.motion`), apart from the link.

## Options
- **Document it (rec)**: sound set in a daily's link lasts until a reload; set it in the panel to keep it, or use an ordinary design link. A line in the probing lore; nothing to build.
- **Keep the exempt preferences in the daily's address**: `snd` (or every exempt preference that differs from its default) stays in the rewritten address. The address then carries the preference, so it is no longer the bare one for those links.
- **Save the sound mode per viewer, as Motion is**: the sound mode would be remembered outside the link and the daily preferences, for every design. A new saved setting and a rule for how a link's value meets it.

## How to check
1. Open the link, tap the maze: no sound. The address bar is now bare.
2. Reload and tap: the music plays (as reported, and as the code reads).
3. Set Sound mode to none in the panel and reload: it should stay none, because a daily remembers a panel choice.
